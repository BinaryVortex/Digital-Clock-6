# Digital-Clock-6

A clean, minimal digital clock built with HTML, CSS and JavaScript.

![App screenshot](Screenshot%202024-07-03%20112231.png)

## Overview

This small project shows a responsive digital clock that displays the current time and updates every second. It's intended as a simple example for learning DOM manipulation, CSS styling, and working with dates in JavaScript.

## Features

- 24/12-hour style display (configurable in code)
- Live time updates every second
- Clean, centered UI with simple styling
- Easy to customize (fonts, colors, size)

## Demo / Screenshot

The screenshot above demonstrates the clock's default appearance. To try it yourself, open the project locally.

## How to run

1. Clone or download the repository:

   git clone https://github.com/BinaryVortex/Digital-Clock-6.git

2. Open `index.html` in your web browser (double-click or use "Open File").

3. (Optional) Use a local development server for live reload (e.g., the VS Code Live Server extension).

## File structure

- `index.html` — markup and container for the clock
- `style.css` — styles and layout
- `script.js` — JavaScript that updates the time
- `Screenshot 2024-07-03 112231.png` — project screenshot used in this README

## Customize

- Change colors and fonts in `style.css`.
- Modify time format or add features (date, timezone) in `script.js`.
